# covid-forecasting-joint-learning
COVID-19 forecasting model for East Java cities using Joint Learning 

> **Research status:** the committed joint-learning experiment was produced with training and evaluation defects, so its results do not establish whether joint learning improves forecasting. See [INVESTIGATION.md](INVESTIGATION.md) before reproducing or extending experiments.
